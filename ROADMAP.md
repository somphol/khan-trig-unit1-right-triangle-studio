# Roadmap

This is a single-maintainer teaching project. The list below is a direction, not
a promise; priorities follow learner value and accessibility.

## Shipped

- [x] Unit 1 companion: ratio constancy, special triangles, reciprocal ratios,
      practice sandbox.
- [x] Full English ⇄ Thai interface.
- [x] Local progress, badges and JSON export.
- [x] Static CI checks and release documentation.

## Next candidates

- [ ] **Keyboard-operable canvas vertices.** Move A and C with arrow keys and
      announce the resulting angle, so dragging is not the only direct
      manipulation.
- [ ] **Reduced-data mode.** Remember a preference for fewer animations and
      softer glow effects beyond the OS-level media query.
- [ ] **Printable worksheet view.** A clean black-on-white export of the current
      triangle, ratios and practice problem.
- [ ] **More practice variants.** Angle-given-two-sides, inverse-trig prompts and
      multi-step mixed problems.
- [ ] **Teacher notes.** A one-page facilitation guide per module.
- [ ] **Additional locales.** Keep the Thai glossary stable and extract strings
      only if a third language is genuinely maintained.

## Explicit non-goals

- Accounts, cloud sync, leaderboards or classroom dashboards.
- Server-side grading or analytics.
- Framework migration for its own sake.
- Advertising, tracking or third-party embeds.

## How to influence it

Open a feature request using the template and describe the learner problem, not
only the UI you want. Accessibility fixes and translation corrections are
usually fast-tracked.
